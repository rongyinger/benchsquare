# Harbor / ALE 示例目录

个人数据看板 → 查看示例。每种格式 16 条，共 32 条。格式筛选支持与比赛、状态、搜索叠加；清除筛选恢复全部记录。

所有审核意见、得分、赛程和文件均为合成演示，不代表真实审核。Harbor 压缩包为界面验证用的最小任务包，包内 README 明确其边界；ALE 使用六类可检查的小型任务，附件包含实际 CSV 输入和 JSON 参考输出。示例下载不依赖外部网盘。

| 场景 | 每种格式条数 | 状态与可见行为 |
| --- | ---: | --- |
| 未关联比赛草稿 | 1 | 可编辑；先关联比赛才能正式提交 |
| 完整草稿 | 1 | Harbor 包已准备；ALE 纯文本任务无需附件 |
| 未完成的比赛草稿 | 1 | 可保存；Harbor 缺包，ALE 缺软件与验证标准，均未勾承诺 |
| 补正中的修改草稿 | 1 | 保留 v1 与补正意见，另存未提交的 v2 工作副本 |
| 首次提交待初审 | 2 | 分别覆盖代码与图表任务；只读，可查看提交内容 |
| 补正后重提待初审 | 1 | 当前 v2 审核中；旧 v1 补正意见不作为当前结果 |
| 初审通过、终检中 | 1 | 展示初审通过记录，等待当前版本终检 |
| 审核需补正 | 1 | 展示具体修改要求，提供修改重提入口 |
| 连续两轮审核不通过 | 1 | v1、v2 分别展示理由；不开放编辑 |
| 审核通过待录用 | 1 | 展示最终得分，保留只读提交快照 |
| 首次提交录用 | 2 | 分别覆盖数据清洗和文档抽取任务 |
| 补正后录用 | 1 | v1 需补正；v2 初审、终检及录用意见与得分完整 |
| 三轮补正待处理 | 1 | v1–v3 有独立内容与逐轮意见；当前仍可补正 |
| 零分审核通过 | 1 | 得分 0.00 正常展示，区别于历史缺少得分 |

默认统计为草稿 8、审核中 8、审核结果 10、已录用 6。按单一格式筛选时分别为 4、4、5、3；顶部统计始终表示本人全部记录。

ALE 示例覆盖 API 重试、依赖锁定、时区归一、图表单位换算、订单表格抽取、两层材料热传导。包含 Windows/Linux/MacOS、三类软件许可、纯文本任务、输入与参考结果文件、Markdown 验证标准及跨版本补正内容。未完成草稿故意保留缺项，其余正式版本满足 ALE 表单字段规则。

旧目录补齐按用户和稳定 ID 去重，仅增加缺少的示例，不覆盖已有记录和恢复工作区。示例移除按当前身份执行，保留个人创建数据；全部移除后不会自动重新载入，需再次点击“查看示例”。

验证：`node frontend/data-items.test.cjs` 与 `node frontend/example-catalog-browser.test.cjs`。

提交版本卡片均可折叠，当前版本默认展开，历史版本默认收起。Harbor 卡片正文保留压缩包下载链接；ALE 卡片正文显示“预览提交”，在弹窗展示对应版本的完整字段与附件。审核意见仍留在所属版本卡片中，预览和折叠不改变任何记录。
