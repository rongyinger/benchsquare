# Competition cover photography

Photos downloaded from Unsplash on 2026-10-19 for illustrative competition covers. These do not depict actual organizers or submitted competition data.

The filename-to-photo-ID mapping is in sources.json. Original image URLs use https://images.unsplash.com/photo-{id}. License: https://unsplash.com/license.

All 18 seeded competitions have different covers. User-created competitions fall back to a domain cover.
